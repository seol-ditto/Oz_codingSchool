## 2. DB 모델 작성
- DBMS : MySQL
    - 이유 : 기본 코드 자체가 MySQL을 가정한 상황이고, SQLite로 설정하고 작업을 시작하니 생각보다 바꿔야 할 설정 자체가 많았다. (BigInt 등) 그래서 기본 코드를 따라 MySQL을 사용해보기로 팀 상의 끝에 결정했다.
    - SQLite는 서버 없이 실행이 가능한 장점이 있었지만, 이후 배울 Docker 등을 고려해서 MySQL을 이번 과제에서 먼저 경험해보기로 결정
    - 터미널에서 `uv add aiomysql`을 실행해 uv.lock에 추가하고 git status로 `pyproject.toml`, `uv.lock` 두 파일이 모두 modified 상태인지 확인
    - 팀원들 모두 `uv sync`로 같은 환경 설정
- ERD 참고하여 파트 분배 (~ 10/24 토요일 23:59까지)
