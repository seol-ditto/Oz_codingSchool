## 1. GitHub를 통해 프로젝트 템플릿 가져오기
1. 팀장이 원격 레포지토리 생성
2. git clone으로 파일 로컬에 복제
3. 해당 원격 레포로 연결
    - clone 받은 템플릿을 `main` branch에 push
4. git remote 추가
5. 팀원 Repository Collaborators로 초대
6. 팀원들이 우리 팀 레포에서 git clone -> git remote 하지않아도 됨

## 2. 팀 규칙 작성하기
- `dev` 브랜치 생성
- 모두 상의하며 `docs/1일차_team_rules.md` 작성
- PR 올리고 `main` 브랜치로 merge
