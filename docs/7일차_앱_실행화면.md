- 캡처

  - 실패:![회원가입 실패](images/Day7_회원가입_실패.png)
- 동작 설명: 이메일, 비밀번호, 이름, 부서, 성별, 휴대폰 번호를 입력해 가입하면 계정이 생성되고(권한은 승인 대기) 로그인 화면으로 이동한다. 이미 가입된 이메일로 가입하면 409 오류와 안내 문구가 표시된다.

- 캡처
