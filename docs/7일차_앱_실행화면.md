- 담당: 이지희
- API: POST /api/v1/auth/logout
- 화면 경로: 로그인 상태의 상단 로그아웃 버튼 → 로그인 화면
- 캡처
  - 성공: ![로그아웃 성공](images/Day7_로그아웃_성공.png)
  - 실패: ![로그아웃 실패](images/Day7_로그아웃_실패.png)
- 동작 설명:
  - 로그인 상태에서 로그아웃 버튼을 클릭하면 확인창 없이 로그인 화면으로 이동한다.
  - 서버 로그에서 POST /api/v1/auth/logout 요청의 200 OK 응답을 확인했다.
  - 로그아웃 후 발급받은 토큰의 재사용 차단 여부는 별도 검증하지 않았다.
  - 실패: 인증 토큰 없이 Swagger에서 로그아웃 API를 호출한 결과, 401 Unauthorized와 "인증 정보가 유효하지 않습니다." 메시지를 확인했다.

## 7. 회원 정보 수정 (REQ-USER-007)

- 담당: 이지희
- API: PATCH /api/v1/users/me
- 화면 경로: 마이페이지 → 정보 수정
- 캡처
  - 성공: ![회원 정보 수정 성공](images/Day7_회원정보수정_성공.png)
  - 변경 결과: ![회원 정보 변경 결과](images/Day7_회원정보수정_결과.png)
  - 실패: ![회원 정보 수정 실패](images/Day7_회원정보수정_실패.png)
- 동작 설명:
  - 성공: 의료진 계정의 전화번호를 010-0000-0002에서 010-0000-0012로 변경했다. 성공 알림과 기본 정보에 변경된 값이 표시되는 것을 확인했다.
  - 실패: 전화번호를 공란으로 두고 정보 저장을 클릭하면 브라우저에서 "이 입력란을 작성하세요." 안내가 나타나 저장이 차단된다.
  - 실패 사례는 브라우저의 필수 입력 검증이며 API 오류 응답은 아니다.

## 8. 비밀번호 변경 (REQ-USER-008)

- API: PATCH /api/v1/users/me/password
- 화면 경로: 마이페이지 → 비밀번호 변경
- 캡처
  - 성공: ![비밀번호 변경 성공](images/Day7_비밀번호변경_성공.png)
  - 실패: ![비밀번호 변경 실패](images/Day7_비밀번호변경_실패.png)
- 동작 설명:
  - 성공: 올바른 현재 비밀번호와 새로운 비밀번호를 입력하면 "비밀번호가 변경되었습니다." 알림이 표시된다. 서버 로그에서 200 OK 응답을 확인했다.
  - 실패: 현재 비밀번호를 잘못 입력하면 "현재 비밀번호가 일치하지 않습니다." 안내가 표시된다. 서버 로그에서 400 Bad Request 응답을 확인했다.

## 13. 환자 정보 상세 조회 (REQ-PTNT-003)

- 담당: 이지희
- API: GET /api/v1/patients/{patient_id}
- 화면 경로: 환자 관리 → 김오즈 상세보기
- 캡처
  - 성공: ![환자 상세 조회 성공](images/Day7_환자상세조회_성공.png)
  - 실패: ![환자 상세 조회 실패](images/Day7_환자상세조회_실패.png)
- 동작 설명:
  - 의료진 계정으로 등록된 환자 김오즈의 상세 화면에 접근했다.
  - 이름 김오즈, 나이 27세, 성별 여성, 연락처 010-1234-5678이 정상 표시되는 것을 확인했다.
  - 서버 로그에서 GET /api/v1/patients/1 요청의 200 OK 응답을 확인했다.
  - 진료기록이 등록되지 않아 "등록된 진료 기록이 없습니다."라는 안내가 표시됐다.
  - 실패: 존재하지 않는 환자 ID(99999)로 상세 화면에 접근했을 때 "존재하지 않는 환자입니다."라는 오류 안내가 표시되는 것을 확인했다.

## 14. 환자 정보 수정 (REQ-PTNT-004)

- 담당: 이지희
- API: PATCH /api/v1/patients/{patient_id}
- 화면 경로: 환자 관리 → 환자 상세보기 → 정보 수정
- 캡처
  - 성공: ![환자 정보 수정 성공](images/Day7_환자수정_성공.png)
  - 성공 알림: ![환자 정보 수정 알림](images/Day7_환자수정_성공알림.png)
  - 실패: ![환자 정보 수정 실패](images/Day7_환자수정_실패.png)
- 동작 설명:  
  - 성공: 김오즈의 전화번호를 010-1234-5678에서 010-1234-5679로 변경했다. 성공 알림이 표시되고 상세 화면에도 수정된 전화번호가 유지되는 것을 확인했다.
  - 실패: 전화번호를 공란으로 두고 수정 완료를 클릭하면 "이 입력란을 작성하세요." 안내가 나타나 저장이 차단된다.
  - 영문자 및 최대 길이를 초과한 숫자의 입력이 제한되는 것도 확인했다.
  - 실패 사례는 브라우저 입력 검증이며 API 오류 응답은 아니다.
