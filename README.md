## 5. 프로젝트 세팅
- `uv sync`로 프로젝트 의존성을 설치하고, `uv`로 Python 패키지와 실행 환경을 관리한다.
- MySQL 데이터베이스를 준비하고 `.env`에 DB 연결 정보와 `SECRET_KEY`, `REFRESH_SECRET_KEY`를 설정한다. 두 SECRET_KEY는 서로 다른 값으로 설정한다.
- AI 예측에 필요한 모델 가중치를 `worker/models/` 경로에 준비한다.
- Alembic 마이그레이션을 적용한 뒤 `uv run fastapi run app/main.py`로 서버를 실행한다.
- 회원가입 및 권한 설정을 통해 테스트 계정을 준비하고, API 동작을 확인한다.

- DB 마이그레이션: [3일차 DB 마이그레이션](docs/3일차_db_migration.md)
- 테스트 계정: [테스트 계정 가이드](docs/7일차_테스트계정_가이드.md)

### Alembic Migration Guide

이 프로젝트는 데이터베이스 마이그레이션을 위해 Alembic을 사용합니다.

#### 1. 마이그레이션 파일 생성 (자동 생성)
모델(`app/models/`)이 변경된 경우 다음 명령어를 실행하여 마이그레이션 파일을 생성합니다.
```bash
uv run alembic revision --autogenerate -m "변경 내용 설명"
```

#### 2. 데이터베이스에 반영
생성된 마이그레이션을 데이터베이스에 적용하려면 다음 명령어를 실행합니다.
```bash
uv run alembic upgrade head
```

#### 3. 이전 상태로 되돌리기 (Rollback)
마지막 마이그레이션을 취소하려면 다음 명령어를 실행합니다.
```bash
uv run alembic downgrade -1
```

## 7. 화면 연결 및 실행 확인
- 제공받은 프론트엔드 템플릿을 프로젝트의 FastAPI 백엔드와 연결해 웹 화면에서 주요 기능을 확인했다.
- X-Ray 이미지와 히트맵을 조회할 수 있도록 파일 경로 처리 및 관련 API를 연동했다.

- 이지희 담당 기능인 회원 정보 수정, 비밀번호 변경, 로그아웃, 환자 상세 조회 및 수정 기능의 동작을 확인했다.
- 테스트 결과와 실행 화면을 캡처해 7일차 앱 실행화면 문서에 정리했다.
